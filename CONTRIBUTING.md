# Contributing

Put your code in `benchmarks/mpra/` or `benchmarks/atac/`.
Include a short README with data sources, dependencies, one command to run the
benchmark, and a description of its outputs. Record the genome assembly,
AlphaGenome model version, genomic splits, metric definitions, and sample counts.

Create a branch, commit your changes, and open a pull request. Contributors without
write access can fork this repository and open a pull request from their fork.

Keep API keys, large datasets, predictions, and logs outside Git.
Discuss manuscript changes in the shared Google Doc linked from the README.
